DriveWay — kaunsi file kis kaam ki

DriveWay.apk        → Customer + Rider ka EK app. Phone par install karo (release, signed).
DriveWay-Admin.apk  → Sirf admin ke phone ke liye. Play Store par nahi jaata.
PlayStore/          → Google Play Console ke liye:
                        DriveWay.aab   = upload wali file (Release → App bundle)
                        icon-512.png, feature-graphic-1024x500.png, screenshots/ = Store listing
                        README.md      = naam, description, Data safety aur baaki forms ke jawab
